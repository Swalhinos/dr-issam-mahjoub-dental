# Centre Dentaire Al Qods — Website

Official website of Centre Dentaire Al Qods (Dr. Omari Abdelhakim), Béni Mellal, Morocco.

Built with Next.js, React, TypeScript and Tailwind CSS.
Languages: English, Spanish, German and Arabic (with full RTL support).

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run start
```
